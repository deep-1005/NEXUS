# NEXUS
Geospatial- Detecting Urban Land Use Change with Satellite Imagery
Problem Statement: Build a model that uses satellite imagery from two different time points to automatically detect and map changes in land use. The output should highlight areas that have changed from vegetation to urban construction, or from water body to barren land.
Possible Datasets: Sentinel-2 Satellite Data, EuroSAT or UC Merced Land Use
